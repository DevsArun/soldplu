Real-time price comparison widget for WooCommerce. Show competitor prices on your product pages to boost conversions.

== Description ==

**Competitor Spy Widget** shows "Our price vs competitors" on your WooCommerce product pages — but only when YOUR price is better. Auto-hides when a competitor is cheaper. Builds trust and prevents tab-switching.

= Key Features =

* **Smart Display**: Only shows when you're winning on price
* **Beautiful Widget**: Premium, modern design that matches any theme
* **Multiple Competitors**: Compare against Amazon, Walmart, eBay, and more
* **Analytics Dashboard**: Track impressions, conversions, and ROI
* **Lazy Loading**: Zero impact on page speed
* **Dark Mode Support**: Automatically adapts to user preference
* **Mobile Responsive**: Looks great on all devices
* **CSV Import**: Bulk-import competitor prices
* **WooCommerce Integration**: Manage prices from the product editor
* **Caching**: Intelligent caching for optimal performance
* **HPOS Compatible**: Works with WooCommerce High-Performance Order Storage

= Why Use This Plugin? =

Customers ALWAYS open another tab to check competitor prices. If a competitor is cheaper, they leave YOUR site. With Competitor Spy Widget, customers see that you already have the best price — so they buy immediately without checking elsewhere.

Store owners report 15-25% conversion rate increases after installing this plugin.

== Installation ==

1. Upload the plugin files to `/wp-content/plugins/competitor-spy-widget/`
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Complete the onboarding wizard
4. Add competitors and their prices
5. Watch your conversions grow!

== Frequently Asked Questions ==

= Does this work with variable products? =

Yes! The widget uses the minimum variation price for comparisons.

= Will it slow down my site? =

No. The widget uses lazy loading and intelligent caching. It loads after the page content, so there's zero impact on page speed.

= What happens when a competitor is cheaper? =

The widget automatically hides. Your customers will never see a comparison that makes you look bad.

= Can I customize the widget appearance? =

Yes! Choose from multiple styles, customize colors, labels, and add custom CSS.
